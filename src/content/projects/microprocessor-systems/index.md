E155 at Harvey Mudd pairs an iCE40 UltraPlus FPGA with an STM32L432KC microcontroller. I wrote SystemVerilog for the FPGA and bare-metal C for the microcontroller, and debugged both with testbenches, an oscilloscope and a logic analyzer. Each lab built on the one before, and the final project put both chips to work together.
